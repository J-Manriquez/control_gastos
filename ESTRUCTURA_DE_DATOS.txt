Firestore
├── usuarios (Colección)
│   ├── {userId} (Documento: UserModel)
│   │   ├── uid: string
│   │   ├── username: string
│   │   ├── email: string
│   │   ├── userShortId: string (para búsquedas de amigos)
│   │   ├── creationDate: Timestamp
│   │   ├── userType: string
│   │   ├── friendsList (Mapa)
│   │   │   ├── accepted: array de {userId}
│   │   │   ├── pending: array de {userId}
│   │   │   └── blocked: array de {userId}
│   │   ├── sharedExpensesMap (Mapa: {expenseId}: {archivado: boolean})
│   │   ├── notifications (Subcolección)
│   │   │   ├── {notificationId} (Documento: NotificationModel)
│   │   │       ├── id: string
│   │   │       ├── title: string
│   │   │       ├── message: string
│   │   │       ├── type: string (friendRequest, sharedExpense, chat)
│   │   │       ├── sourceId: string (ID de la solicitud o gasto)
│   │   │       ├── senderId: string
│   │   │       ├── timestamp: Timestamp
│   │   │       ├── isRead: boolean
│   │   │       └── additionalData: map
│   │   │
│   │   └── expenseGroups (Subcolección)
│   │       ├── {expenseId} (Documento: Gasto)
│   │           ├── id: string
│   │           ├── nombre: string
│   │           ├── valor: double
│   │           ├── fecha: Timestamp
│   │           ├── esAFavor: boolean
│   │           ├── archivado: boolean
│   │           ├── groupName: string (si aplica, para agrupar gastos personales)
│   │           ├── expenses: array de Gasto (para gastos agrupados)
│   │           ├── subgroups: array de SubgroupModel (para gastos agrupados)
│   │           └── type: string (GastoType.normal)
│   │
│   └── ...otros usuarios
│
├── sharedExpenses (Colección)
│   ├── {expenseId} (Documento: SharedExpenseGroup)
│   │   ├── id: string
│   │   ├── groupName: string
│   │   ├── total: double
│   │   ├── creatorId: string
│   │   ├── participants: array de {userId, status, customPercentage}
│   │   ├── expenses: array de Gasto (Gastos individuales dentro del grupo)
│   │   ├── subgroups: array de SubgroupModel
│   │   ├── creationDate: Timestamp
│   │   ├── permissionType: string
│   │   ├── version: string
│   │   ├── lastModified: Timestamp
│   │   ├── expenseDistributions: map de {expenseId}: DistributionModule
│   │   ├── subgroupDistributions: map de {subgroupId}: DistributionModule
│   │   ├── totalDistribution: DistributionModule
│   │   ├── archivado: boolean
│   │   ├── currentVersion: string
│   │   └── versions (Subcolección)
│   │       ├── {versionId} (Documento: VersionVoteModel)
│   │           ├── timestamp: Timestamp
│   │           ├── data: map (datos de la versión del gasto)
│   │           ├── previousVersion: string
│   │           ├── modifierId: string
│   │           ├── votes: array de {userId, status, timestamp}
│   │           ├── status: string (pending, accepted, rejected)
│   │           ├── changeTypes: array de string
│   │           └── changeDetails: map
│   │
│   └── ...otros gastos compartidos
│
├── friendRequests (Colección)
│   ├── {requestId} (Documento: FriendRequestModel)
│   │   ├── requestId: string
│   │   ├── fromUserId: string
│   │   ├── toUserId: string
│   │   ├── status: string (pending, accepted, rejected, blocked)
│   │   └── timestamp: Timestamp
│   │
│   └── ...otras solicitudes de amistad
